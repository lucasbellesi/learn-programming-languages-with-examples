# Learner Solution Rubric

Use this rubric for exercises, projects, and assessments in every language track.
Score each dimension from 0 to 2; a complete submission scores at least 8/10 and has
no zero in correctness or boundaries.

| Dimension | 0 | 1 | 2 |
| --- | --- | --- | --- |
| Correctness | Normal behavior is wrong | Main scenario works partially | All named contract cases pass |
| Boundaries | Invalid or empty input breaks the program | Some boundaries are handled | Documented limits and errors are explicit |
| Idioms | Fights the language model | Mostly readable with avoidable translation | Uses native types, APIs, and resource patterns |
| Design | Duplicated or tightly coupled | Responsibilities are visible | Invariants and responsibilities are clear |
| Explanation | Cannot explain choices | Explains the main path | Explains tradeoffs, failure modes, and alternatives |

For guided work, hints used are evidence about the next topic to revisit, not a score
penalty. Assessments should be completed without step-by-step scaffolding.
