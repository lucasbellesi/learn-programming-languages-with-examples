# Repository Instructions

## Git Workflow

- Use `master` as the integration branch for this repository.
- Before starting a new set of changes, fetch `origin` and create a new branch from
  the latest `origin/master`. Use the `codex/` prefix for agent-created branches.
- Make changes and commits on the working branch, never directly on `master`.
- Run the checks required by `CONTRIBUTING.md`, push the working branch, and open
  a pull request targeting `master`.
- Continue revisions for an open pull request on its existing branch.
- Do not merge the pull request unless the user explicitly requests it.

## Contributions

Follow [CONTRIBUTING.md](CONTRIBUTING.md) for curriculum, documentation, and
validation requirements. Keep repository content in English.
